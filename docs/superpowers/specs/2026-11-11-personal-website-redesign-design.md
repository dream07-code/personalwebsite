# NOVA 个人网站重设计

## 目标

为一名计算机学生重建可长期维护的个人网站，以「技术博客 + 项目作品 + 关于我」为核心，先作为静态站部署到 Cloudflare Pages。旧代码按用户要求全部废弃，不保留旧视觉和页面结构。

## 设计方向

- 近黑背景 `#080a0d`、略亮面板 `#101419`、主文字 `#edf4f2`、次要文字 `#8c999d`。
- 青色 `#64e6e2` 用于光标、链接和交互描边，嫩绿色 `#b7f77d` 用于状态与少量强调。
- 大字号英文标题搭配清晰的中文正文；等宽字体用于日期、编号和状态标签。
- 背景使用低对比度网格和径向光晕，卡片采用圆角、细边框和局部辉光，避免堆砌玻璃拟态。
- 参考 kanin.cn 的个人表达、aohs.top 的近期文章结构、xustalis.site 的长期内容沉淀，但不复制其页面。

## 页面与内容

1. 首页：导航、个人首屏、技术栈、精选项目、近期文章、关于我摘要、联系页脚。
2. 文章：列表、按标签筛选入口、Markdown 详情页、代码块与阅读时长。
3. 项目：列表与 Markdown 详情页，展示技术栈、年份、仓库和演示链接。
4. 关于我：个人介绍、学习方向、当前关注、联系方式。
5. 系统页面：404、RSS、sitemap、robots.txt。

`src/site.config.ts` 是身份、域名和社交链接的唯一配置源。NOVA、示例文章与示例项目均为可替换演示内容，不代表用户真实经历。

## 光标互动

- 仅在精确指针设备且用户未要求减少动态效果时启用。
- 默认状态：8px 青色光点 + 36px 圆角方形描边，跟随鼠标但有轻微惯性。
- 链接与按钮：描边扩大并变为青色。
- 卡片：出现青色边框、四个定位角标、随指针移动的径向辉光；布局不位移。
- 触屏、键盘导航和 `prefers-reduced-motion` 下保留原生交互与清晰焦点，不隐藏系统光标。

## 技术方案

### 选定：Astro 静态内容站

Astro 6 + TypeScript + 原生 CSS，内容集合管理 Markdown，构建输出 `dist/`。优势是文章和项目维护成本低、页面 JS 少、RSS/sitemap 成熟，适合 Cloudflare Pages。

### 未选：React 单页应用

React 更适合复杂客户端状态；本站以内容阅读为主，使用 SPA 会增加 JS 和路由成本，没有明显收益。

### 未选：纯 HTML 多页面

零构建很简单，但文章详情、共用布局、RSS 与内容校验会重复劳动，不利于长期更新。

## 约束与验收

- Node 22，Astro 6.4.8；不引入后端、数据库或客户端框架。
- 375px、768px、1024px、1440px 宽度下无横向滚动，导航可用。
- 所有可点击元素有 hover/focus 状态；正文对比度清晰；图片和图标有可访问名称。
- 核心工具函数和光标判断有自动化测试；`npm run test`、`npm run build` 均通过。
- Cloudflare Pages 构建命令为 `npm run build`，输出目录为 `dist`，环境变量 `NODE_VERSION=22`。
- 不代为发布或登录 Cloudflare；交付可构建仓库与部署说明。
